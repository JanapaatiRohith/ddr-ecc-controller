# IP configuration notes

`mig_config/mig_7series_0.xci` is the MIG customization file from the supplied source bundle. The current 2025.2 project archive generated from the active `arty_ecc25` project is the authoritative snapshot for the latest MIG and replacement Clock Wizard IP. The old `arty_clock_wiz` Rev. 19 XCI was created by Vivado 2026.1 and is intentionally omitted from this active IP folder; the final project uses the Vivado 2025.2-compatible `arty_clock_wiz_v25` IP.
